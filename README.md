# DSLR | Data Science & Logistic Regression

A data science project focused on data exploration, visualization and machine learning. The goal is to analyze a dataset, identify relevant features and build a logistic regression model from scratch to solve a classification problem.

## Overview

This project is divided into three steps, progressively moving from data analysis to machine learning.

- **Step 1: Data Analysis**  
  Explore the dataset using descriptive statistics and data visualization.

- **Step 2: Data Visualization**  
  Analyze relationships between features and identify patterns that can help distinguish classes.

- **Step 3: Logistic Regression**  
  Implement a logistic regression classifier from scratch and use it to predict student houses.

The project emphasizes understanding the data before building a model, as well as implementing the underlying mathematical concepts rather than relying entirely on existing machine learning libraries.
